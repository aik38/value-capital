# VALUE CAPITAL

`value-capital.jp` 向けの静的Webサイトです。GitHub Pagesを前提とし、サイト本体はGitHub、案件・フォームデータはGoogleスプレッドシート、機密資料はGoogle Driveで分離管理します。

## ページ
- `/` トップ（LP型）
- `/deals/` 売却案件一覧（ノンネーム情報）
- `/valuation/` 査定依頼
- `/buyer/` 買手登録
- `/company/` 会社概要
- `/privacy/` プライバシーポリシー
- `/terms/` 利用・免責事項

個別案件詳細ページは作成しません。トップページの案件CTAは `/deals/#案件ID` へ遷移して該当案件まで案内し、`/deals/` の「この案件の詳細情報を希望する」から `/buyer/?deal=案件ID` へ進み、案件IDを自動入力します。

## 案件表示・導線
- トップページの案件カードはコンパクト表示を維持します。
- `/deals/` のM&A案件は、案件ID・地域・業種・公開見出し・売上・譲渡理由を基本表示とします。
- ホテル・旅館等は、客室規模や不動産所有形態など案件固有で有用な公開項目を必要に応じて表示します。
- 利益状況・希望スキーム・希望条件・売却時期等はGoogleスプレッドシートに保持しますが、M&A案件一覧の標準表示にはしません。
- 公開見出しでは全角縦棒 `｜` を使用せず、読点 `、` で統一します。
- 事業用不動産は、土地面積・建物・現況・想定用途・希望条件・売却時期・所有形態等から、値がある公開項目のみ表示します。

## データ管理
- `案件管理`：内部マスター。正式会社名、正式所在地、担当者、内部メモ、DriveフォルダURL等を保持可能。
- `公開用案件データ`：Web APIへ返してよい公開項目のみ。
- `査定依頼`：売主・相談者フォームの保存先。
- `買手登録`：買手情報と対象案件IDの保存先。

公開Webは `公開用案件データ` のみ読み取ります。内部案件マスターをブラウザへ返さないでください。

## Google Apps Script
`gas/Code.gs` をApps Scriptへ配置します。

Script Properties:
- `SPREADSHEET_ID`：VALUE CAPITAL案件管理スプレッドシートID
- `TURNSTILE_SECRET`：Cloudflare Turnstile利用時のみ

WebアプリのURLは `assets/js/config.js` の `GAS_ENDPOINT` に設定します。現在はGASの公開案件APIを使用し、`USE_SEED_DATA:false` で運用します。

## Cloudflare Turnstile
Cloudflareでサイトキーとシークレットを作成し、
- `assets/js/config.js` → `TURNSTILE_SITE_KEY`
- Apps Script Properties → `TURNSTILE_SECRET`
へ設定します。

現状の `TURNSTILE_SITE_KEY` は空欄です。導入する場合は上記設定を行ってください。

## SEO・公開状態
本番サイトは `https://value-capital.jp/` で公開しています。

- `robots.txt` は `Allow: /` で通常クロールを許可
- トップ、案件一覧、査定依頼、買手登録、会社概要は検索対象
- プライバシーポリシーと利用・免責事項は `noindex` のまま維持
- `sitemap.xml` に主要公開ページを掲載
- 福岡・九州のM&A、企業価値評価、事業用不動産査定を意識したtitle・description・OGPを設定
- トップページにOrganization構造化データを設定
- Google Search Consoleのドメインプロパティを運用対象として確認済み

SEO設定変更後はSearch Consoleでクロール・インデックス状況、検索クエリ、表示回数、クリック数を確認してください。

## UI・レスポンシブ
PC・スマホで同一の情報設計を使用しつつ、スマホでは見出しの孤立改行を避けるため専用の改行位置を設定しています。

案件一覧はスマホで1列表示とし、ラベル幅・余白を調整しています。フッターはブランド説明、売主・ご相談者、買手企業を主導線とし、補助リンクは「会社概要」「プライバシーポリシー」のみに整理しています。コピーライトは `© 2019–2026 VALUE CAPITAL` です。

`/terms/` ページ自体は維持しますが、フッターには常設リンクを表示しません。

`/privacy/` は、取得情報・利用目的・第三者提供/業務委託・安全管理・Cookie/アクセス解析・開示/訂正等・問い合わせの必要項目に絞った簡潔な構成とし、制定日の表示は行いません。

## 補足・運用メモ
- `assets/img/*.svg` は外部ホットリンクを避けるためのローカル建築ビジュアルです。本番写真へ差し替える場合は `assets/img/` にWebPで保存してください。
- `data/public-deals.seed.json` はGAS障害時・開発確認用のフォールバックです。案件運用の正本にはしません。
- 案件情報の正本はGoogleスプレッドシートです。公開内容の変更時は `案件管理` と `公開用案件データ` の整合を確認してください。
